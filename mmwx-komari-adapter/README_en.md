## Introduction

**MMWX Probe Komari Theme Adapter** is a self-hosted read-only probe frontend that adapts MMWX Probe data for Komari themes.

## Features

- **Theme Adapter**: Loads static or frontend-build Komari themes from a GitHub repository.
- **Probe Proxy**: Proxies probe status, historical data, and the real-time WebSocket stream with a read-only boundary.
- **Theme Management**: Verifies an administrator token and saves theme settings through the management endpoint.

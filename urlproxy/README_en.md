## Introduction

**URLProxy** is a tool for speeding up downloads of remote resources by proxying requested URLs through a server with better network connectivity.

## Features

- **URL proxy downloads**: Proxies target resources through the /proxy/{URL} route.
- **Access protection**: Supports an access password and allowed proxy domain whitelist to reduce abuse risk.
- **CORS and download behavior**: Supports configuring CORS access and whether proxied content is forced to download.

## Introduction

**SeekMeow** is a lightweight tool that monitors NodeSeek RSS posts, filters posts by keyword, keyword group, regular expression, or category rules, and pushes matched results to MeoW.

## Features

- **Direct RSS monitoring**: Reads the official NodeSeek RSS feed without requiring a NodeSeek account, cookies, or a browser.
- **Flexible matching**: Supports keywords, keyword groups, regular expressions, category filters, and block keywords.
- **Persistent state**: Stores processed post IDs and retry messages in a local state file to avoid duplicate notifications.

## Introduction

**Firefox** is an open-source web browser developed by Mozilla. This app is based on the `jlesage/firefox` container image and runs Firefox in Docker with browser-based GUI access.

## Features

- Web GUI: access Firefox from a browser through port 5800.
- Persistent configuration: stores configuration, state, logs, and persistent files under `/config`.
- Web File Manager: optional web-based file manager.
- CJK fonts and Web Audio: supports CJK fonts and Web Audio.

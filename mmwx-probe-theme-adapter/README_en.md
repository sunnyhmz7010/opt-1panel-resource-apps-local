## Introduction

**MMWX Probe Theme Adapter** is a self-hosted multi-theme probe adapter powered by MMWX Probe data, with support for Komari and minimalist probe themes.

## Features

- **Multi-theme Adapter**: Loads static or frontend-build Komari and minimalist probe themes from GitHub repositories.
- **Probe Proxy**: Proxies probe status, historical data, and the real-time WebSocket stream with a read-only boundary.
- **Theme Management**: Verifies an administrator token and saves theme settings through the management endpoint.
